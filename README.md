# EZ Bet

Five NFL player props, ranked by how often each one hit over a player's last 8 games. Search any team or player and the five re-rank.

## Run it
Double-click `index.html`, or in this folder run `python3 -m http.server 8000` and open http://localhost:8000.

## Real vs. not real
- **Real:** every player, game date, opponent and stat in `data.js` comes from ESPN's public game logs (pulled 2026-10-27). 233 players on all 32 teams (QB, RB, WR, TE with 8 games and a regular role).
- **Not real:** the **lines**. Each starts as a fixed "typical line" chosen for this site (for example Over 3.5 receptions, Over 39.5 receiving yards). If a player cleared it in all 8 games, `app.js` raises it to just above his lowest game, so no pick shows 8 of 8 (the 7-of-8 is partly built in, because the line is fitted to the same 8 games). They are NOT DraftKings lines. **There are no odds**, so the −300 to +300 window from the brief is not applied.
- "Hit rate" is a past count, not a probability of winning. It doesn't check injuries, byes or matchups.
- ESPN's API is unofficial and can change or disappear.

## Refresh the data
`data.js` is generated by a pull script that is not part of the site. Re-run it each week to replace `data.js`. When fewer than 8 games exist in 2026, it fills in with late-2025 regular-season games.

## Deploy
Static site: GitHub Pages or Netlify Drop (app.netlify.com/drop). All paths are relative. No keys or secrets in this folder.
